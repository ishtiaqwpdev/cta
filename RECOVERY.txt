CTA LMS SITE RECOVERY (white screen / timeout)
==============================================

Git push alone cannot unstick a hung PHP server. Do this:

1) Ask hosting support (or use File Manager / FTP):
   - Restart PHP / PHP-FPM (or "Kill PHP processes")
   - In wp-content/plugins/ RENAME these folders if they exist:
       cta-academy-lms  ->  cta-academy-lms.off
       cta-lms          ->  cta-lms.off
       cta-design       ->  cta-design.off
       cta              ->  cta.off
   - Open the website — it should load (without LMS).

2) Upload the fixed zip: cta-academy-lms.zip
   (It ships in SAFE MODE via DISABLE_CTA_LMS_BOOT.)

3) Activate "CTA Academy LMS". Site should still load.

4) When ready to turn LMS back on:
   - Delete file: wp-content/plugins/cta-academy-lms/DISABLE_CTA_LMS_BOOT
   - OR add to wp-config.php: define('CTA_LMS_FULL_BOOT', true);
